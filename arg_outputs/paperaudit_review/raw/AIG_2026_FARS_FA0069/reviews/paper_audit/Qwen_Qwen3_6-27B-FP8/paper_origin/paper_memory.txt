# Global Summary

This paper investigates the problem of handling truncated rollouts in Reinforcement Learning with Verifiable Rewards (RLVR) for long Chain-of-Thought (CoT) reasoning. The standard approach treats truncation (hitting token limits) as a failure ($R=-1$), which biases the model against long reasoning. The authors propose "timeout bootstrapping," which treats truncation as a timeout rather than a terminal state, using the critic's value estimate at the truncation point as the reward signal.

The study conducts a pre-registered comparison of three strategies on the DeepSeek-R1-Distill-Qwen-1.5B model using the MATH-500 dataset. Key findings indicate that timeout bootstrapping fails to outperform baselines on average (52.50% vs 53.80% on long problems) due to a critical failure mode: the critic's value estimates collapse to -1.0 within 15–20 training steps. However, on stable training runs, the method shows promise (+2.20pp over baseline). Mechanistic analysis reveals the critic is fundamentally miscalibrated, exhibiting a negative correlation with correctness (Pearson $r = -0.211$, AUROC = 0.314).

# Abstract

- **Problem:** RLVR enables long CoT reasoning, but rollouts must be truncated at maximum token lengths. Standard practice treats truncation as failure, conflating unfinished reasoning with incorrect reasoning.
- **Proposal:** Timeout bootstrapping. Drawing from classical RL theory, truncation is treated as a timeout, not a terminal state. The agent bootstraps from the critic's value estimate rather than assigning a failure reward.
- **Evaluation:** Pre-registered comparison of three truncation strategies on mathematical reasoning using DeepSeek-R1-Distill-Qwen-1.5B.
- **Key Results:**
    - Timeout bootstrapping fails pre-registered criteria on average: 52.50% vs 53.80% baseline on long problems.
    - Shows promise on stable runs: +2.20pp over baseline.
- **Failure Mode:** Critic value estimates collapse to -1.0 within 15–20 training steps, rendering bootstrapping equivalent to truncate-as-failure.
- **Mechanistic Analysis:** The critic exhibits negative correlation with correctness (Pearson $r = -0.211$, AUROC = 0.314), indicating fundamental miscalibration.

# Experiments

- **Setup:**
    - **Model:** DeepSeek-R1-Distill-Qwen-1.5B.
    - **Training Data:** DAPO-Math-17k.
    - **Evaluation:** MATH-500 (Hendrycks et al., 2021).
    - **Metrics:** Pass@1 accuracy (All problems and "Long" subset).
    - **Long Subset:** 125 problems (top 25% by median base model generation length, threshold 6568 tokens).
    - **Hyperparameters:** PPO with GAE ($\gamma = 1.0, \lambda = 1.0$). Batch size 256 prompts, 8 responses each. Actor LR $10^{-6}$, Critic LR $10^{-5}$. Max length $L_{max} = 16384$ tokens.
    - **Seeds:** 2 random seeds per condition (42 and 137).

- **Conditions:**
    - **Condition A (Truncate-as-Failure):** Standard approach. $R = -1$ if truncated.
    - **Condition B (DAPO Overlong Shaping):** Soft length penalty ramping up as responses approach token limit.
    - **Condition C (Timeout Bootstrapping):** Proposed method. $R = \text{clip}(V_{\phi}(s_T), -1, +1)$ if truncated. Includes delayed bootstrapping (first 10 steps use $R=-1$) and entropy bonus (0.001).

- **Main Results (Table 1):**
    - **Baseline A (seed 137):** Best overall performance. Pass@1 All: 85.30%, Pass@1 Long: 55.20%.
    - **Condition C (seed 42):** Pass@1 All: 84.60%, Pass@1 Long: 54.60%. This is +2.20pp over the same-seed baseline A (52.40%).
    - **Condition C (seed 137):** Diverged due to entropy explosion. Pass@1 Long: 50.40%.
    - **Average Performance:** Condition C mean long-subset Pass@1 (52.50%) is 1.30pp below best baseline A (53.80%). 95% bootstrap CI includes zero.
    - **Collapse Incidence:** Condition C had 1/2 seeds diverge; Baselines had 0/2.

- **Training Dynamics (Figure 2):**
    - **Critic Value Collapse:** In Condition C, critic value at truncation ($V(s_T)$) drops to -1.0 by training step 15–20. Fraction of positive bootstrapped values remains 0.0%.
    - **Entropy:** Baselines A and B show entropy collapse (below 0.2 nats). Condition C seed 42 maintains entropy (0.75 nats) due to bonus, but seed 137 explodes (8.4 nats) causing divergence.
    - **Truncation Rates:** Condition B achieves lowest truncation rate (12.2%) due to length penalty. Condition C diverged seed has highest rate (34.2%).

- **Value Informativeness (Table 2):**
    - Analyzed critic values on completed rollouts at different prefix positions.
    - **Correlation:** Critic exhibits negative correlation with final correctness.
    - **90% Prefix Stats:** Pearson $r = -0.211$ ($p < 0.001$). AUROC = 0.314 (worse than random).
    - **Mean Values:** Critic assigns lower values to correct responses (Mean $V = -0.377$) than incorrect ones (Mean $V = -0.083$).

# Discussion

- **Interpretation:** Timeout bootstrapping shows promise on stable seeds (+2.20pp) but fails on average due to two failure modes.
- **Failure Mode 1: Critic Value Collapse:** The critic learns a pessimistic prior (-1.0) before encountering enough positive examples. Excluding truncated rollouts from critic training may starve the critic of necessary supervision.
- **Failure Mode 2: Entropy Instability:** The entropy bonus (0.001) prevents collapse in stable runs but causes explosion in unstable runs. This suggests a need for more sophisticated entropy control (e.g., EntroPIC).
- **Critic Miscalibration:** The critic is trained from scratch on sparse rewards with long horizons. It likely learns spurious features (e.g., associating longer/complex prefixes with lower reward) rather than semantic correctness.
- **Limitations:** Limited statistical power (2 seeds, 100 steps). Results may not generalize to larger models or different domains. The 1.5B model may lack capacity for accurate value estimation.
- **Future Directions:** Critic pre-training, auxiliary objectives for intermediate reasoning quality, curriculum-based critic warmup, and including truncated rollouts in critic training.
