# Global Summary
Long-context language models exhibit position bias, under-utilizing middle positions and degrading retrieval-augmented generation performance. Iterative Attention Sorting mitigates this by repeatedly reordering documents based on attention patterns, but requires k+1 prefill passes (e.g., 6 passes for k=5), increasing latency. The authors propose Debiased One-Pass Attention Sorting, which estimates a per-prompt position-bias curve from distractor documents and subtracts it from raw attention scores to enable single-pass sorting (2 prefill passes). Evaluated on the SynthWiki benchmark (~28K tokens, 200 examples per seed across 3 seeds) using LLaMA-2-7B-32K-Instruct and YaRN-Llama-2-7b-64k, the hypothesis that position bias is the primary bottleneck is refuted. On LLaMA-2-7B-32K-Instruct, debiasing yields identical results to uncalibrated single-pass sorting (94.83% accuracy, 0 improvement across 600 examples). On YaRN-Llama-2-7b-64k, debiasing improves accuracy by 8.67 percentage points but remains 14.84pp behind k=5 iterative sorting (70.67%), closing only 37% of the gap. The authors conclude that iterative sorting provides benefits beyond bias correction, likely from attention context refinement and error reduction across passes. Caveats include evaluation on only two models and one benchmark, and a disclaimer that the paper was generated by an automated research system.

# Abstract
- Problem: Long-context LLMs suffer from position bias ("lost-in-the-middle"). Attention Sorting fixes this iteratively but requires multiple expensive prefill passes.
- Hypothesis: Position bias is the primary bottleneck; explicitly estimating and subtracting it from attention scores should enable single-pass sorting to match iterative performance.
- Method: Debiased One-Pass Attention Sorting estimates a per-prompt position-bias curve from distractor documents and subtracts it from raw attention scores.
- Results: Hypothesis refuted. On LLaMA-2-7B-32K-Instruct, debiasing produces identical results to uncalibrated k=1 sorting (94.83% accuracy). On YaRN-Llama-2-7b-64k, debiasing improves accuracy by 8.67 percentage points but remains 14.84pp behind k=5 sorting, closing only 37% of the gap.
- Claims: Position bias is not the primary bottleneck on well-tuned models. Iterative sorting provides benefits beyond bias correction, likely from attention context refinement across passes.
- Note: Paper generated by an automated research system; code publicly available.

# Method
- Problem Setup: Long-context extractive QA with a query and N documents concatenated into one prompt. Exactly one document contains the answer. Goal is to reorder documents so the relevant document appears in a high-attention position (typically the end) before answer generation.
- Attention Sorting Baseline: Computes raw attention mass a_i for each document by aggregating attention weights from the first generated token across all layers and heads. Documents are sorted by ascending a_i. Process repeats for k iterations. Requires k+1 prefill passes (k sorting passes + 1 generation pass). For k=5, this equals 6 prefill passes.
- Debiased One-Pass Sorting: Extracts raw attention masses using a single decode step. Estimates a position-bias curve b(p) from attention-position pairs within the prompt. Trims the top alpha fraction of documents by attention (default alpha = 0.05) to exclude likely relevant documents. Bins remaining positions into B equal-width bins (default B = 20), computes median attention per bin, and interpolates to obtain a continuous curve. Computes debiased scores s_i = a_i - b(p_i) (additive) or s_i = a_i / b(p_i) (divisive). Reorders documents by s_i and generates the answer. Requires only 2 prefill passes.

# Experiments
- Dataset: SynthWiki benchmark (synthetic long-context extractive QA, one gold document among distractors). Contexts constructed to approximately 28K tokens by sampling distractors until the limit, with shuffled document order.
- Models: LLaMA-2-7B-32K-Instruct (moderate position bias, instruction-tuned) and YaRN-Llama-2-7b-64k (severe recency bias, context-extended, no instruction tuning).
- Baselines & Methods: No Sorting (1 prefill), Attention Sort k=1 (2 prefills), Debiased k=1 (2 prefills), Attention Sort k=5 (6 prefills).
- Metrics & Protocol: Exact-match accuracy. Greedy decoding. 200 examples per seed across 3 random seeds (42, 123, 456).
- LLaMA-2-7B-32K-Instruct Results: No Sorting achieves 72.83% ± 2.84%. Attn Sort k=1 achieves 94.83% ± 1.44%. Debiased k=1 achieves 94.83% ± 1.44% (byte-identical to uncalibrated k=1 across all 600 examples: 0 wins, 600 ties, 0 losses). Attn Sort k=5 achieves 95.50% ± 0.71%. The gap between k=1 and k=5 is 0.67 percentage points.
- YaRN-Llama-2-7b-64k Results: No Sorting achieves 35.83% ± 2.25%. Attn Sort k=1 achieves 47.17% ± 2.25%. Debiased k=1 achieves 55.83% ± 2.08% (+8.67pp over uncalibrated k=1). Attn Sort k=5 achieves 70.67% ± 3.33%. Debiased k=1 remains 14.84pp behind k=5, closing only 37% of the gap.
- Analysis: On LLaMA, uncalibrated k=1 already places the gold document at mean position 164.86 out of ~166 documents, leaving minimal room for bias correction. On YaRN, severe recency bias corrupts raw attention scores, making debiasing beneficial but insufficient. Iterative sorting progression shows accuracy increases from 94.83% (k=1) to 95.83% (k=2), then plateaus at 95.50% (k=5). Gold document position converges to ~165.77/166. Authors attribute residual gains to attention context refinement (changing document adjacency alters cross-document attention) and error accumulation reduction (multiple passes average out attention noise).
