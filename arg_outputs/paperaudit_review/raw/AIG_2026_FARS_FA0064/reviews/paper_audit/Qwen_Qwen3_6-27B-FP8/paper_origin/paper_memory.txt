# Global Summary

The paper addresses the problem of selecting which Transformer layers should retain full attention versus sliding-window attention in hybrid models for efficient long-context inference. The authors propose NLL-guided layer selection, a training-free method that scores layers based on the negative log-likelihood (NLL) degradation on answer tokens when a layer switches from full to sliding-window attention. Evaluated on Qwen3-4B using the LongMemEval benchmark, the method achieves 64.6% accuracy using only 1/4 full-attention layers, matching the 1/2-FA periodic baseline (65.0%) while halving the computational budget. The approach outperforms the best periodic 1/4-FA pattern by 10.4 percentage points and attention-based heuristics by 26.4 percentage points. Calibration requires approximately 15 minutes on 4 GPUs and amortizes after roughly 1,354 inference requests at 24k prompt length. The authors note limitations regarding evaluation on a single model and benchmark.

# Abstract

- Problem: Hybrid attention models require selecting specific layers for full attention; existing methods use fixed patterns or heuristics that may not optimize downstream accuracy.
- Method: NLL-guided layer selection measures importance by computing NLL degradation on answer tokens when a layer uses sliding-window instead of full attention.
- Key Results: On LongMemEval with Qwen3-4B, the method achieves 64.6% accuracy with 1/4 full-attention layers. This matches the 1/2-FA periodic baseline (65.0%) and outperforms the best periodic 1/4-FA pattern by 10.4 percentage points and attention-based heuristics by 26.4 percentage points.
- Efficiency: Calibration takes ~15 minutes on 4 GPUs. The method advances the efficiency-accuracy Pareto frontier.
- Caveat: The paper includes a warning that it was generated by an automated research system.

# Introduction

- Context: LLMs face quadratic complexity in self-attention for long-context tasks. Hybrid attention (mixing full and sliding-window) offers a middle ground.
- Prior Work: SWAA (Yu et al., 2025) adapts pretrained models to sliding-window attention. LightTransfer (Zhang et al., 2024) uses attention-based heuristics.
- Gap: The choice of layers for full attention significantly impacts performance; on Qwen3-4B, the gap between good and poor 1/4-FA selections exceeds 26 percentage points.
- Proposal: NLL-guided selection directly measures output quality degradation.
- Contributions:
  - Training-free method for layer selection.
  - NLL-guided 1/4-FA achieves 64.6% accuracy on LongMemEval, matching 1/2-FA periodic (65.0%) with half the budget.
  - Mechanistic validation shows the NLL signal is specific to long-range needs (Spearman rho = 0.306 between long and short-prompt rankings).
  - Practical calibration (~15 minutes on 4 GPUs) amortizes after ~1,354 inference requests at 24k prompt length.

# Method

- Problem Formulation: For a Transformer with L layers and a budget of k layers for full attention during prefill, select set S to maximize downstream accuracy. Full-attention decode is always enabled.
- Scoring: Per-layer score is defined as the reduction in mean NLL on answer tokens when the layer uses full attention instead of sliding-window attention during prefill. Formula: Delta_l = L_ans(SWA at layer l) - L_ans(FA at layer l).
- Procedure: Uses teacher forcing with forward passes only. SWA is applied to prompt tokens; answer tokens attend to full context.
- Selection: Select top-k layers by Delta_l. Selected layers naturally span early, middle, and late depths.
- Calibration: Requires 64 long-context examples (16k-32k tokens). Performs L+1 forward passes per example. Takes ~15 minutes on 4 GPUs for a 36-layer model. No gradient computation.
- Inference: Selected layers use full attention during prefill; others use sliding-window. All layers use full attention during decode. Break-even point is ~1,354 requests at 24k prompt length.

# Experiments

- Setup:
  - Model: Qwen3-4B-Thinking-2507 (36 layers).
  - Benchmark: LongMemEval (500 samples, 6 task types, ~24k tokens average).
  - Configuration: SWAA with sliding window size 2048, keep-first-10 attention sinks, full-attention decode.
  - Calibration Data: 64 examples from LongAlign-10k and fusang-v1-filtered (16k-32k tokens).
  - Generation: vLLM, 8 GPUs, batch size 64, temperature 0. Judge: GPT-5-mini.
- Baselines: Full Attention, 1/2-FA Periodic, 1/4-FA Periodic, LightTransfer 1/4-FA, Naive SWA.
- Main Results (Table 1):
  - Full Attention: 73.0% accuracy.
  - 1/2-FA Periodic: 65.0% accuracy.
  - NLL-Guided 1/4-FA: 64.6% accuracy (Selected layers: 1, 3, 9, 10, 12, 13, 15, 21, 34).
  - 1/4-FA Periodic: 54.2% accuracy.
  - LightTransfer 1/4-FA: 38.2% accuracy.
  - Naive SWA: 3.2% accuracy.
- Per-Task Analysis (Table 2): NLL-Guided outperforms LightTransfer on all 6 task types. Largest improvements: single-session-user (+37.1 percentage points) and temporal-reasoning (+33.9 percentage points).
- De-confounding Analysis:
  - Comparison of layer rankings from long-prompt (16k-32k tokens) vs short-prompt (1.5k tokens) calibration.
  - Spearman correlation rho = 0.306 (p = 0.069).
  - Jaccard similarity between selected layers = 0.2 (3 of 9 overlap).
  - Long-prompt Delta-NLL values are 85.6x larger in magnitude than short-prompt values.
- Layer Selection Patterns: Selected layers span early (1, 3), middle (9-15, 21), and late (34) depths. Layer 15 has the highest Delta-NLL (0.011).
- Calibration Stability:
  - Using 16 examples vs 64 examples yields Jaccard similarity of 0.64 (7 of 9 layers overlap).
  - Accuracy with 16 examples is 62.2% (2.4 percentage point drop from 64.6%).
  - Core layers (9, 13, 15, 21) are consistently selected.

# Conclusion

- Summary: NLL-guided layer selection is a principled, training-free method for hybrid sliding-window models. It achieves 64.6% accuracy with 1/4 full-attention layers, matching the 1/2-FA periodic baseline (65.0%) while halving the computational budget.
- Performance: Outperforms fixed periodic patterns by 10.4 percentage points and attention-based heuristics by 26.4 percentage points.
- Limitations: Evaluation is limited to a single model (Qwen3-4B) and benchmark (LongMemEval).
- Future Work: Validate across model families and tasks; explore dynamic per-input layer selection.
