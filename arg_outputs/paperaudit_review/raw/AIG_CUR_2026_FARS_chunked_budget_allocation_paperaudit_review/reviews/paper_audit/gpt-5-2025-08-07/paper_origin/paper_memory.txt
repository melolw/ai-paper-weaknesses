# Global Summary
- Problem: Verifying irreversible actions (e.g., checkout) with world models can backfire under sequential verify-and-retry; increasing verification budget can reduce task success due to trajectory drift (re-browsing after a rejection leads to worse product choices).
- Approach: Chunked budget allocation. Given budget B world-model calls, allocate across M verification cycles with K = B/M parallel rollouts per cycle; set M = 1 to spend all budget in one parallel chunk and eliminate sequential retries. Decision uses either consensus (p̂ ≥ τ) or a single rollout; after M cycles, later checkouts auto-pass (budget exhausted).
- Evaluation: WebShop. 600 episodes per condition (200 tasks per seed × 3 seeds) from a pool of 500 tasks. Acting agent: Gemini-2.5-Flash (temp 1.0). World model: fine-tuned Qwen2.5-7B via vLLM (temp 0.7, top-p 0.9). Episode limit 50 steps. All conditions use B = 10; 95% bootstrap CIs.
- Key results:
  - Main comparison at B = 10: Sequential (A) 0.86% [0.17, 1.72]; Chunked Consensus (B) 14.83% [12.00, 17.67] (+14.01 pp vs A); Chunked No-Agg (C) 21.50% [18.33, 24.83] (+20.67 pp vs A). Paired bootstrap CI for C–A: [+17.50, +24.00] pp. Reported as a “25×” improvement (21.50% vs 0.86%).
  - Varying cycles with fixed B = 10 (τ = 0.5 for this study): M = 1 → 20.0%; M = 2 → 8.5%; M = 5 → 14.0%; M = 10 → 0.8% (also noted as 0.83%). Extremes show ~24× improvement from M = 10 to M = 1.
  - Consensus often fails because the world model is poorly calibrated: in Condition B, p̂ = 0.0 for 98.4% of cycles (306/311), yet when p̂ = 0.0 the actual success rate is 27.5% (84/306). Brier score = 0.28; ECE = 0.28. Rare p̂ > 0 (5/311) all succeeded.
  - Failure analysis where chunked (B) succeeded but sequential (A) failed (n = 81): Trajectory drift 60.5% (49), Wrong product checkout 27.2% (22), Never reached checkout 12.3% (10). Only 2 reverse cases (A > B), net +79 successes for chunked.

# Abstract
- Problem: Sequential verify-and-retry with world models for irreversible actions can reduce task success as verification budget increases due to trajectory drift after rejections (often false negatives).
- Proposal: Chunked budget allocation—use fewer cycles with more parallel rollouts per cycle; ideally M = 1 (single parallel chunk).
- Results on WebShop: Chunked verification (M = 1) achieves “21.50%” task success vs “0.86%” for sequential (M = 10), a “25×” improvement at the same budget. Consensus across parallel rollouts provides no benefit over single-rollout acceptance because the world model predicts failure for “98.4% of cycles,” causing consensus to degenerate.
- Takeaway: Budget allocation structure > aggregation when world models are poorly calibrated.

# Introduction

# Method
- Problem setup (WebShop): Text-based e-commerce; agent observes search/product pages and can search, click, and checkout; checkout ends the episode. Acting agent: Gemini-2.5-Flash. World model: fine-tuned Qwen2.5-7B. Given trajectory h and action a, WM predicts next observation s′ and binary success R′ ∈ {0,1} (purchase satisfies intent).
- Verification framework:
  - Budget B spread across M verification cycles with K = B/M parallel rollouts per cycle.
  - On checkout proposal, generate K stochastic WM predictions; compute consensus p̂ = (1/K) Σ 1[R′k = 1].
  - Proceed if p̂ ≥ τ, else block and continue browsing. After M cycles, any subsequent checkout auto-passes (budget exhausted).
- Experimental conditions (all with B = 10):
  - Condition A (Sequential Verify-and-Retry): K = 1 per cycle; if R′ = 1 proceed, else block; up to M ≈ 10 cycles.
  - Condition B (Chunked Consensus): M = 1, K = 10; proceed if p̂ ≥ τ; τ = 0.1.
  - Condition C (Chunked No-Aggregation): M = 1, K = 10; decision uses only the first rollout’s R′ (no consensus). Isolates effects of fewer cycles vs aggregation.

# Experiments
- 4.1 Experimental setup:
  - Benchmark: WebShop (500 test tasks). Evaluation uses 200 randomly sampled tasks per seed across 3 seeds → 600 total episodes per condition.
  - Metric: Task success rate (purchased product satisfies user intent).
  - Agents: Acting agent Gemini-2.5-Flash (temperature 1.0). World model: fine-tuned Qwen2.5-7B via vLLM (temperature 0.7, top-p 0.9).
  - Protocol: Max 50 steps per episode. All conditions B = 10. Report 95% bootstrap CIs over 600 episodes.
- 4.2 Main results (Table 1):
  - A (Sequential, ~10 cycles, K = 1): 0.86% success; 95% CI [0.17, 1.72].
  - B (Chunked Consensus, M = 1, K = 10): 14.83%; 95% CI [12.00, 17.67]; Δ vs A = +14.01 pp.
  - C (Chunked No-Agg, M = 1, K = 10): 21.50%; 95% CI [18.33, 24.83]; Δ vs A = +20.67 pp.
  - Paired bootstrap CI for C–A: [+17.50, +24.00] pp. C outperforms B by 6.67 pp.
- 4.3 Mechanism analysis: cycle reduction (fixed B = 10; τ = 0.5 for this study):
  - Success rates: M = 1 (K = 10) 20.0%; M = 2 (K = 5) 8.5%; M = 5 (K = 2) 14.0%; M = 10 (K = 1) 0.8% (also noted as 0.83%).
  - Authors attribute the non-monotonicity at intermediate M to τ interacting with K (e.g., with K = 5, τ = 0.5 requires ≥3 positives; with K = 2, τ = 0.5 requires both positives) under high WM false-negative rates. Extremes (M = 1 vs M = 10) show a ~24× advantage for fewer cycles.
- 4.4 Failure analysis: trajectory drift (episodes where B succeeded but A failed; n = 81; Table 2):
  - Trajectory drift: 49 (60.5%).
  - Wrong product checkout: 22 (27.2%).
  - Never reached checkout: 10 (12.3%).
  - Only 2 episodes with the reverse pattern (A succeeded, B failed); net +79 successes for chunked.
- 4.5 Temperature ablation (M = 2, K = 5, τ = 0.5; Table 3):
  - WM temp 0.7: A 0.83%, B 8.50%, B–A +7.67 pp; 95% CI [5.50, 10.00].
  - WM temp 0.0: A 7.67%, B 17.33%, B–A +9.67 pp; 95% CI [6.33, 13.17].
  - Under temp 0, all K rollouts identical (p̂ ∈ {0,1}), indicating benefits stem from reduced sequential cycles rather than stochastic diversity.
- 4.6 Why consensus aggregation fails:
  - In Condition B, across 311 verification cycles, p̂ = 0.0 in 98.4% (306/311).
  - Calibration: Brier score 0.28; ECE 0.28.
  - When p̂ = 0.0, actual success rate is 27.5% (84/306). Rare p̂ > 0 (5 cycles) all succeeded. Majority voting cannot recover when all K predict failure; gains come from eliminating sequential cycles, not aggregation.

# Conclusion
- Findings: Allocation structure dominates aggregation sophistication for irreversible-action verification with poorly calibrated world models. Chunked verification with M = 1 (all budget in one parallel chunk) prevents non-monotonic regressions and yields “25×” improvement at the same budget (21.50% vs 0.86%), mainly by avoiding trajectory drift.
- Limitations: Single domain (WebShop) and single world model (Qwen2.5-7B); absolute success remains modest (“21.50%”).
- Future work: Test generalization to other irreversible domains, improve world-model calibration (potentially enabling consensus), and design adaptive allocation strategies that adjust M by task difficulty.
