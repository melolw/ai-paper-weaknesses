# Global Summary

**Problem:** Agent memory systems suffer from "false memory storage," where assistant-generated content enters persistent memory without user confirmation. The root cause is identified as "assistant-originated self-verification," where assistant statements serve as evidence to verify their own validity during the filtering stage.

**Core Approach:** The authors propose Speaker-Attested Grounding (SAG), a minimal intervention that restricts the evidence corpus used for memory filtering to user turns only, while maintaining full-dialogue context for the initial extraction stage. This prevents assistant-originated false memories from self-verifying.

**Evaluation Scope:** The method is evaluated on the HaluMem-Medium benchmark (5-user subset, 343 dialogue sessions). The system uses GPT-4o-mini for extraction and filtering (temperature 0) and GPT-4o as the judge model.

**Key Findings:**
- SAG (relaxed) improves False Memory Resistance (FMR) by +11.94 percentage points (58.76% → 70.70%) compared to the Dialogue-Wide baseline.
- This improvement comes with a recall tradeoff of -7.20 percentage points (53.14% → 45.94%).
- Per-source analysis shows 100% of SAG's FMR gains come from assistant-only interference memories (+4.6pp), with no change on user-repeated interference.
- Ablation studies attribute 47.5% of the improvement to the speaker restriction mechanism itself, with the remaining 52.5% due to reduced evidence length.

**Caveats:** SAG involves a recall tradeoff. It cannot address "semantic overlap" errors where users discuss the same topic as the interference memory, providing genuine user-turn evidence that the filter cannot distinguish from false content.

# Introduction

- **Context:** Agent memory systems enable long-term personalization but are susceptible to false memory storage (interference memories).
- **Hypothesis:** Restricting the evidence corpus to user turns will target assistant-originated false memories while preserving legitimate user-stated memories.
- **Proposed Solution:** Speaker-Attested Grounding (SAG), a minimal single-variable intervention changing only the evidence corpus construction.
- **Contributions:**
    - Identification of "assistant-originated self-verification" as a root cause.
    - Proposal of SAG, improving FMR by +11.94pp on HaluMem.
    - Demonstration that 100% of FMR gains come from assistant-only interference.
    - Ablation analysis isolating speaker restriction (47.5% of gains) from evidence length effects (52.5%).

# Method

- **Problem Formulation:**
    - Standard pipelines use a two-stage process: extraction followed by verification.
    - Standard verification uses the full dialogue as evidence ($E_{full}$), allowing assistant statements to verify themselves.
- **Speaker-Attested Grounding (SAG):**
    - Restricts the evidence corpus to user turns only ($E_{SAG}$).
    - Extraction still uses the full dialogue to capture all potentially relevant information.
    - Filtering rejects candidates that cannot be grounded in user statements.
    - This is a single-variable intervention; all other pipeline components remain identical.
- **Grounding Threshold Variants:**
    - **SAG (strict):** Requires explicit user statements to support a memory candidate. Prioritizes false memory resistance.
    - **SAG (relaxed):** Allows user-implied content (reasonable inference). Maintains higher recall with slightly lower filtering stringency.

# Experiments

- **Experimental Setup:**
    - **Dataset:** HaluMem-Medium benchmark (5-user subset, 343 dialogue sessions). Dataset license: Not specified.
    - **Models:** GPT-4o-mini (temperature 0) for extraction/filtering; GPT-4o for evaluation/judging.
    - **Metrics:** Recall (coverage of gold memories), False Memory Resistance/FMR (fraction of interference memories rejected), F1, Avg Memories.
    - **Baselines:** Extract-Only (no filtering), Dialogue-Wide (full dialogue evidence).
    - **Number of runs:** Not specified (deterministic temperature implies single run per configuration).
    - **Error bars:** Not specified.

- **Main Results (Table 1):**
    - **Dialogue-Wide Baseline:** Recall 53.14%, FMR 58.76%, F1 66.63.
    - **SAG (relaxed):** Recall 45.94% (-7.20pp), FMR 70.70% (+11.94pp), F1 60.66.
    - **SAG (strict):** Recall 43.81% (-9.33pp), FMR 74.42% (+15.66pp), F1 58.69.
    - **Observation:** Dialogue-Wide provides minimal improvement over Extract-Only (FMR 58.76% vs 56.90%), confirming that full dialogue evidence allows false memories to pass.

- **Per-Source Analysis (Figure 2):**
    - **Interference Breakdown:** 645 total interference memories. 70.9% assistant-only (n=457), 27.8% user-repeated (n=179), 1.4% neither.
    - **Assistant-Only:** SAG achieves 91.25% FMR vs Dialogue-Wide 86.65% (+4.6pp).
    - **User-Repeated:** Both methods achieve 80.45% FMR (no change).
    - **Conclusion:** 100% of SAG's overall FMR improvement comes from the assistant-only subgroup.

- **Ablation Study (Table 2):**
    - **Token-Matched Baseline:** Truncates dialogue-wide evidence to match SAG's average length (controls for length effects).
    - **Results:** Token-Matched achieves FMR 66.98% (accounting for 52.5% of SAG's gain).
    - **Attribution:** The speaker restriction mechanism itself accounts for the remaining 47.5% (+7.44pp).
    - **Recall Impact:** Token-Matched suffers severe recall degradation (33.99%) compared to SAG (strict) at 43.81%, showing SAG achieves a more favorable recall-FMR tradeoff.

- **Error Analysis:**
    - **False Positives:** 100% exhibit "semantic overlap" (user discussed the same topic as the interference memory, providing genuine evidence the filter cannot distinguish).
    - **False Negatives:** 87% are cases where the LLM filter missed available evidence due to extraction inaccuracies (SAG correctly rejected these). 13% represent genuine recall losses (implied but not explicit info).
