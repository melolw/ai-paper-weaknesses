# Global Summary
- Problem: Efficient long-context inference via sparse attention routing. Learned routers require per-head training, while training-free alternatives like symmetric k-means suffer from query-key distribution mismatch and limited quality.
- Core Approach: Proposes GWR Linear, a training-free routing method that predicts attention mass per bucket using closed-form ordinary least squares (OLS). Tests and discards geometric moment matching (gauge-coupled whitening) as ineffective for routing.
- Evaluation Scope: Tested on Qwen2.5-7B using 6 prompts from the PG19 dataset at 32K context length. Compares against symmetric k-means, random routing, and a learned MLP router (Saap-MLP).
- Key Findings: GWR Linear achieves 72.6% attention-mass recall@32, closing 63.6% of the performance gap between symmetric k-means (51.3%) and Saap-MLP (84.8%). Gap closure scales with routing budget (44.3% to 80.3%) and generalizes across attention heads (mean 69.8% across 6 heads spanning layers 2–26).
- Caveats: The paper explicitly states it was generated by an automated research system. The authors note a remaining ~12.2 percentage point gap to learned routing, indicating non-linear patterns exist that linear prediction cannot capture.

# Abstract
- Investigates whether training-free routing can approach learned router quality for sparse attention.
- Tests geometric moment matching via dot-product-preserving gauge transforms; finds it provides no improvement over symmetric k-means (50.7% vs 51.3% recall).
- Proposes GWR Linear, which predicts attention mass per bucket via closed-form OLS computation without iterative training.
- On Qwen2.5-7B, achieves 72.6% attention-mass recall@32, closing 63.6% of the gap between symmetric k-means (51.3%) and a learned MLP router (84.8%).
- Gap closure increases with routing budget (44%–80%) and generalizes across 6 attention heads spanning layers 2–26 (mean 69.8%).
- Notes the paper was generated by an automated research system and code is publicly available.

# Method
- Problem Setup: Routes queries to l out of C=1024 key buckets. Metric is attention-mass recall@l, defined as the fraction of a query's total attention weight captured by selected buckets.
- Gauge-Coupled Whitening: Explores dot-product-preserving transformations (q' = qR, k' = kR^{-top}) to align query and key second moments via ZCA-style whitening. Solves S M_q S = M_k in closed form.
- Failure of Geometric Matching: GWR Geometric achieves 50.7% recall@32, identical to symmetric k-means (51.3%). Concludes routing depends on predicting attention mass, not geometric distribution alignment.
- OLS Attention-Mass Prediction: Maps queries to bucket scores via linear predictor W. Computes W* = (Q^top Q + epsilon I)^{-1}Q^top Y using calibration queries Q and true bucket-aggregated attention masses Y. Requires no iterative optimization.
- Complexity: Calibration complexity is O(nd_h^2 + d_h^2C + d_h^3). For n approx 10^5, d_h = 128, C = 1024, calibration takes seconds on a single CPU. Inference complexity is O(d_hC + C log l), matching symmetric k-means routing cost.

# Experiments
- Setup: Evaluates on Qwen2.5-7B (28 layers, 28 heads per layer, d_h=128). Uses 6 prompts from PG19 dataset at 32K context length, yielding approximately 134K long-range queries (distance > 2047 tokens). Routing budget l=32 (3.1% of buckets).
- Baselines: Random, Symmetric K-Means, GWR Geometric, Saap-MLP (learned 2-layer MLP, 50 epochs SGD), and Whitening-Only ablation.
- Main Results: GWR Linear achieves 72.6% ± 0.032 recall@32. Symmetric K-Means achieves 51.3% ± 0.026. Saap-MLP achieves 84.8% ± 0.000. GWR Linear closes 63.6% of the gap. GWR Geometric achieves 50.7% ± 0.027. Whitening-Only achieves 25.0% ± 0.020. Random achieves 0.030 ± 0.000.
- Ablation: Whitening-Only demonstrates that breaking dot-product preservation destroys routing quality, confirming gauge coupling is protective but not performance-enhancing.
- Budget Sweep: Gap closure increases monotonically from 44.3% at l=4 to 80.3% at l=128. At l=128, GWR Linear recall is 88.4% vs Saap-MLP 93.5%.
- Multi-Head Generalization: Tested on 6 heads (L2-H0, L7-H0, L14-H0, L14-H14, L21-H0, L26-H0). Mean gap closure is 69.8% (range 28.8%–92.1%). Highest closure at L7-H0 (92.1%, where symmetric k-means gets 6.7% vs GWR 44.5%). Lowest at L14-H14 (28.8%).
