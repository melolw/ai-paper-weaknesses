# Global Summary

The paper introduces KL-Time Replay, a method for scheduling experience replay in continual learning for Large Language Models (LLMs). Instead of using parameter-space metrics (like accumulated update norms used in FOREVER), the proposed method monitors function-space drift by computing KL divergence between current and reference predictions on fixed anchor sets. The authors evaluate the method on a 5-task text classification benchmark using Qwen3-0.6B with LoRA. Key findings indicate that KL-Time achieves performance comparable to FOREVER (Overall Performance 0.704 vs 0.708) while producing substantively different scheduling decisions (14.24% trigger divergence). The analysis reveals high within-task correlation (>0.97) between the two drift signals, but significant divergence at task boundaries. The authors note that the paper was generated by an automated research system.

# Abstract

- Proposes KL-Time Replay, which monitors function-space drift via KL divergence on fixed anchor sets to trigger replay, replacing parameter-space metrics.
- Compares against FOREVER on a 5-task text classification benchmark.
- Key quantitative results: KL-Time achieves an Overall Performance (OP) of 0.704 compared to FOREVER's 0.708.
- Scheduling decisions differ significantly: 14.24% trigger divergence between the two methods.
- Analysis shows KL drift and parameter update norms are highly correlated within tasks (>0.97) but diverge at task boundaries.
- Warning: The paper states it was generated by an automated research system.

# Method

- **Problem Formulation:** Addresses continual learning over a sequence of $K$ tasks. Uses LoRA for parameter-efficient fine-tuning (updating low-rank adapter matrices while freezing the base model). Maintains a memory buffer $M$ containing a subset of examples from previous tasks.
- **Drift Signal:** Replaces FOREVER's parameter-space "model time" ($\tau_t$, based on accumulated parameter update norms) with a function-space drift signal ($D_t$).
- **Anchor Set Construction:** At the start of task $k$, an anchor set $\mathcal{A}_k$ is constructed by sampling from memory buffers of previous tasks. The set is capped at a maximum size of 256 examples and remains fixed throughout training on task $k$.
- **Metric:** Uses Label-Space KL Divergence. Defines predictive distribution over labels using verbalized labels and prompts. Drift $D_t$ is the mean KL divergence between current model predictions ($q_{\theta_t}$) and reference predictions ($q_{\theta_{ref}}$) on the anchor set. The reference model $\theta_{ref}$ is a frozen snapshot from the start of task $k$.
- **Scheduling:** Adopts an Ebbinghaus-inspired schedule ($\mathcal{D}_{\text{human}} = \{1, 2, 4, 7, 15, 30, \dots\}$). Calibrates a "drift day" using a warm-up window of 24 steps. Thresholds are scaled by a factor $\rho$ to match total replay compute with FOREVER within $\pm 10\%$. Replay triggers when cumulative drift exceeds the threshold.

# Experiments

- **Setup:**
    - **Dataset:** Standard CL benchmark (5-task sequence: AG News $\rightarrow$ Amazon Reviews $\rightarrow$ Yelp Reviews $\rightarrow$ DBpedia $\rightarrow$ Yahoo Answers).
    - **Data Split:** 1000 training instances and 500 evaluation instances per class per task.
    - **Memory:** Buffer stores 2% of each task's training data.
    - **Model:** Qwen3-0.6B base model with LoRA adaptation (rank $r = 8$, $\alpha = 32$, dropout 0.05) on attention query and value projections.
    - **Training:** Learning rate $3 \times 10^{-4}$, batch size 8, 10 epochs per task. Replay events train on the memory buffer for 2 epochs.
    - **Runs:** Results averaged over 9 runs (3 seeds $\times$ 3 task orders).
- **Baselines:**
    - **SeqFT:** Sequential fine-tuning without replay.
    - **VBM:** Step-based Ebbinghaus replay (fixed intervals).
    - **FOREVER:** Model-centric time replay using parameter update norms.
- **Metrics:** Overall Performance (OP, average final accuracy) and Backward Transfer (BWT, measuring forgetting).
- **Main Results:**
    - **OP:** KL-Time achieves 0.704±0.015. FOREVER achieves 0.708±0.014. VBM achieves 0.683±0.025. SeqFT achieves 0.686±0.021.
    - **BWT:** All replay methods achieve near-zero BWT (KL-Time: 0.0002±0.0003; FOREVER: 0.0001±0.0003).
    - **Replay Events:** KL-Time uses 29.9±2.7 events vs FOREVER's 27.2±0.9. Compute ratio is 1.10 (within 10% tolerance).
- **Signal Analysis:**
    - **Correlation:** Within-task Pearson correlations between KL drift and parameter norms are >0.97 (Task 1: 0.979, Task 2: 0.981, Task 3: 0.981, Task 4: 0.992).
    - **Divergence:** Full-trajectory correlations are moderate (Pearson 0.46, Spearman 0.58), indicating divergence at task boundaries.
    - **Trigger Divergence:** Phase-0 gate analysis shows 14.24%±3.24% divergence in replay triggers between KL-Time and FOREVER on early tasks (tasks 1–2), exceeding the 10% threshold for meaningful difference.
- **Ablation Study (Anchor Selection):**
    - **Past-Task Anchors (Default):** OP 0.704±0.015, 29.9±2.7 replay events.
    - **Current-Task Anchors:** OP 0.713±0.014, 18.7±1.6 replay events. Current-task anchors yield higher performance with 37% fewer replay events.
