# Method
- Introduces VidVec-RouteK, a training-free method for adaptive reranking budget allocation based on cross-layer ranking disagreement.
- Problem formulation: Two-stage retrieval where the reranker requires K forward passes per query. Goal is to adaptively select K(q) to reduce average compute while maintaining retrieval quality.
- Multi-layer embedding extraction: Extracts embeddings from layers L = {20, 24, 27} of VideoLLaMA3-7B (28 layers total). Layer 24 serves as the anchor layer for retrieval.
- Cross-layer disagreement signal: Computes D(q) = 1 - (1 / |L| - 1) * Σ Jaccard(T_m^(24)(q), T_m^(ℓ)(q)) for ℓ ∈ L \ {24}. Default m = 20. High disagreement indicates model uncertainty.
- 3-tier routing: Maps D(q) to K ∈ {10, 60, 100} using thresholds τ1, τ2 calibrated on a validation set to achieve avg-K ≈ 30.
- Query distribution: Yields approximately 63% easy queries (K=10), 32% medium queries (K=60), and 5% hard queries (K=100).
- Complexity analysis: Entirely training-free. Additional cost is extracting embeddings from two extra layers via forward hooks and computing Jaccard similarity over m=20, which adds negligible overhead. Primary savings come from reducing average reranker forward passes from 100 to approximately 30, a 70% reduction.

# Experiments
- Experimental setup: Datasets are MSR-VTT 1k-A (1,000 test queries) and DiDeMo (1,004 test queries). Model is VideoLLaMA3-7B (Qwen2.5-7B backbone, 28 transformer layers).
- Baselines: Stage-1 Embedding Only, Fixed K=100, Margin Routing, Disagreement Binary, Disagreement 3-tier.
- Metrics: Recall@1 (R@1), Recall@5 (R@5), Recall@10 (R@10), Mean Rank (MnR), and average reranking budget (avg-K). All routing methods calibrated to avg-K ≈ 30.
- Main results (MSR-VTT): Disagreement 3-tier achieves R@1=53.2, R@5=74.9, R@10=79.6, MnR=25.9, avg-K=30.9. Outperforms Margin Routing (R@1=52.3) by +0.9 R@1. Exceeds Fixed K=100 (R@1=52.5) by +0.7 R@1.
- Main results (DiDeMo): Disagreement 3-tier achieves R@1=53.3, R@5=70.0, R@10=73.2, MnR=53.7, avg-K=30.4. Outperforms Margin Routing (R@1=51.8) by +1.5 R@1.
- 3-tier vs binary routing: 3-tier outperforms binary by +0.4 R@1 on MSR-VTT and +0.9 R@1 on DiDeMo.
- Ablation study (MSR-VTT, binary routing): Default (Layers {20, 24, 27}, Jaccard) R@1=52.8. Alt layers {18, 24, 27} R@1=52.0. Alt metric (Kendall τ) R@1=52.5. Union pool variant R@1=53.1. Margin baseline R@1=52.3.
- Query distribution analysis: Consistent across both benchmarks at ~63% easy, 32% medium, 5% hard.
- Limitations: Evaluated only on VideoLLaMA3-7B and two benchmarks. Future work includes learned routing policies and extension to other modalities.
