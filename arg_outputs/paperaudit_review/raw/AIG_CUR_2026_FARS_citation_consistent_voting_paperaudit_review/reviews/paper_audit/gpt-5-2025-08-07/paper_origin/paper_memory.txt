# Global Summary
- Problem: Retrieval-augmented generation (RAG) is sensitive to the order of retrieved documents; large language models exhibit position bias that yields inconsistent answers across permutations.
- Core approach: Citation-Consistent Voting (CCV), a training-free, inference-time aggregation method that prompts the generator to emit structured citations (answer, cited doc index, quote), verifies evidence, maps citations to permutation-invariant document IDs, and selects the answer with the highest citation-consistency score across K permutations. Ties are broken by raw answer frequency.
- Evaluation scope: NaturalQuestions (NQ) with 3,610 test queries; Contriever Top-5 Wikipedia retrieval; generator is Qwen3-8B with greedy decoding (temperature = 0); metrics are Substring Exact Match (SubEM) and token-level F1; K ∈ {5, 10, 15, 20}.
- Key findings:
  - At K = 20, CCV achieves "46.37% SubEM" and "46.83% F1," outperforming majority voting by "+0.19 SubEM" and "+0.17 F1."
  - Scaling with K is monotonic: ΔSubEM (CCV − MoA) = −0.01 (K=5), +0.10 (K=10), +0.11 (K=15), +0.19 (K=20).
  - Diagnostic analysis: citation agreement correlates with correctness; mean agreement 3.04 (correct) vs. 2.85 (incorrect), Mann–Whitney p = "1.14 × 10^−5."

# Abstract
- Problem: RAG output varies with document ordering due to position bias.
- Proposal: Citation-Consistent Voting (CCV), a training-free method that aggregates by document-ID agreement across permutations. Steps: prompt the model to cite, map citations to permutation-invariant IDs, select answers with maximal citation consistency after evidence checks.
- Results on NaturalQuestions with Qwen3-8B + Contriever: "46.37% SubEM," exceeding majority voting by "+0.19" at "K = 20." Improvement increases with K.

# Introduction
- Motivation: RAG improves factual grounding but is vulnerable to permutation sensitivity and “lost in the middle” effects (Liu et al., 2023). Even with 5 documents, permuting order can cause different, sometimes wrong, answers (Zhang et al., 2026).
- Prior strategies:
  - Training-based (e.g., Stable-RAG) require access to model weights/data.
  - Inference-time ensembles (e.g., Mixture-of-Agents) vote by answer frequency, ignoring citation structure.
- Key observation: Correct answers tend to cite the same underlying document across permutations; incorrect ones vary in citations.
- Method idea: Vote on document-ID agreement among evidence-valid responses rather than on answer frequency.
- Contributions:
  - Propose CCV, a training-free inference-time method using citation structure.
  - Demonstrate +0.19 SubEM over majority voting on NaturalQuestions at "K = 20," with gains increasing monotonically with K.
  - Validate significant correlation between document-ID agreement and correctness (p = "1.14 × 10^−5").

# Related Work
- Position bias: LLMs perform best when relevant info is at the beginning or end; middle-position info degrades performance (Liu et al., 2023). The work tackles this via inference-time aggregation.
- RAG and retrieval: DPR (Karpukhin et al., 2020), Contriever (Izacard et al., 2021) enable dense retrieval for QA; robust RAG must account for position sensitivity. Prior robustness approaches include training-based and inference-time methods.
- Self-consistency and ensembles: Majority voting across sampled reasoning paths (Wang et al., 2022) and multi-agent aggregation (Wang et al., 2024). Permutation self-consistency improves ranking (Tang et al., 2023). CCV reframes the aggregation signal to citation agreement rather than answer frequency.
- Permutation-robust RAG: Stable-RAG (Zhang et al., 2026) uses preference optimization; other works aggregate across orderings. CCV is training-free and leverages explicit citation structure via document-ID agreement.

# Method
- Overview: Three-stage CCV pipeline.
  - Stage 1 (Permutation Sampling): Given query q and N retrieved documents D = {d1,…,dN}, sample K random permutations π1,…,πK.
  - Stage 2 (Per-Permutation Generation): Generate JSON-constrained outputs containing answer, cited document index, and supporting quote; run evidence-validity checks.
  - Stage 3 (Citation-Consistent Voting): Map each cited index to its permutation-invariant underlying document ID; group responses by answer; select answer with highest citation-consistency score.
- Evidence filtering:
  - Each response rk includes answer ak, cited index jk ∈ {1,…,N}, and quote ek.
  - A response is evidence-valid if jk is a valid index, ek appears in d_{πk(jk)}, and ak appears in ek. Invalid responses are filtered.
- Aggregation:
  - docID(rk) = πk(jk) yields a permutation-invariant document identifier.
  - For each unique answer a, with evidence-valid set R(a):
    - doc*(a) = argmax_d |{r ∈ R(a): docID(r) = d}|.
    - score(a) = |{r ∈ R(a): docID(r) = doc*(a)}|.
  - Final selection: argmax_a score(a); tie-breaker is raw answer frequency across all K runs.
- Practical considerations:
  - Quote constraint relaxation: Relaxing exact quote verification to require only valid document index increases coverage; both variants evaluated.
  - Compute: Requires K forward passes (same as multi-permutation baselines); filtering/aggregation overhead negligible; supports batched inference and potential KV-cache sharing.

# Experiments
- Setup:
  - Dataset: NaturalQuestions (Kwiatkowski et al., 2019), "3,610 test queries."
  - Retrieval: Contriever (Izacard et al., 2021), Top-5 Wikipedia passages.
  - Generator: Qwen3-8B, greedy decoding, temperature = 0.
  - Metrics: SubEM (substring exact match) and token-level F1.
  - Baselines: Vanilla RAG (single-pass); Mixture-of-Agents (MoA) Majority Vote over K permutations. K ∈ {5, 10, 15, 20}.
- Main results (Table 1):

  - Vanilla RAG (JSON Citation), K=1: "45.10% SubEM," "45.18% F1."
  - MoA Majority Vote, K=5: "45.82±0.28% SubEM," "46.38±0.21% F1." (Number of runs/seeds not specified in this section.)
  - MoA Majority Vote, K=20: "46.18% SubEM," "46.66% F1."
  - CCV (Ours), K=20: "46.37% SubEM," "46.83% F1." Improvement over MoA: "+0.19 SubEM," "+0.17 F1."
  - Note: Authors state the higher SubEM but lower F1 for the standard prompt vs. JSON prompt reflects output-format differences.
- K-scaling (Figure 2; Table 2):
  - SubEM at K = 5/10/15/20 for MoA: "45.82 / 46.07 / 46.09 / 46.18."
  - SubEM at K = 5/10/15/20 for CCV: "45.81 / 46.17 / 46.20 / 46.37."

- Diagnostic analysis (4.5):

# Conclusion
- Summary: CCV is a training-free, citation-aware aggregation method for permutation-robust RAG that votes on document-ID agreement. On NaturalQuestions, it improves over majority voting by "+0.19 SubEM" at "K = 20," with gains increasing with K; citation agreement strongly correlates with correctness (p = "1.14 × 10^−5").
- Limitations stated: modest absolute improvement; evaluation limited to one dataset and model; requires K forward passes (computational cost).
- Future work suggested: combine with training-based methods (e.g., Stable-RAG), evaluate on more datasets, explore additional citation signals beyond document-ID agreement.
