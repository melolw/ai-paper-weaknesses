# Global Summary
This paper addresses the problem of citation hallucination and unsupported claims in long-form reports generated by deep research agents. The authors propose QuoteVerify, an inference-time verification pipeline that requires models to output structured citation triples containing explicit evidence quotes. These quotes are verified through multi-stage mechanical substring matching and NLI-based entailment gating, followed by a repair-or-drop mechanism. Evaluation on a 20-prompt pilot subset of ReportBench using GPT-4o and Gemini-2.5-Pro shows statistically significant improvements in cited-statement match rates: +18.7 percentage points (p=0.019) for GPT-4o and +12.5 percentage points (p=0.011) for Gemini-2.5-Pro over standard baselines. The authors claim that requiring a structured citation format drives the majority of gains, while quote validity remains the primary bottleneck, with LLMs producing verbatim quotes only 18-28% of the time even when sources are successfully fetched. A noted tradeoff is a substantial drop in coverage (reference recall decreases by 62-66% and cited statement count drops by 38-53%). The paper explicitly states it was auto-generated and provides public code. Training budget is not specified as the method requires no additional training.

# Abstract
- Problem: Deep research agents frequently hallucinate references, fabricate quotes, or cite sources that do not support claimed statements.
- Method: QuoteVerify, an inference-time pipeline prompting models to generate structured citation triples (statement, source_id, evidence_quote). Verification includes source fetching, quote validity checking via substring matching, and NLI-based entailment gating.
- Dataset: ReportBench.
- Key Results: Statistically significant match rate gains of +18.7 percentage points on GPT-4o (p=0.019) and +12.5 percentage points on Gemini-2.5-Pro (p=0.011).
- Analysis: Structured citation format drives most gains. Quote validity is the primary bottleneck; LLMs produce valid quotes only 18-28% of the time for successfully fetched sources, indicating a paraphrasing tendency.
- Caveat: Paper generated by an automated research system; code is publicly available.

# Method
- Architecture: A 5-stage inference-time wrapper requiring no additional training.
- Stage 1 (Structured Triple Generation): Base LLM outputs triples t_i = (statement_i, source_id_i, evidence_quote_i). Evidence quotes are constrained to <=300 characters.
- Stage 2 (Source Fetching): Fetches and caches sources via URL resolution. Handles arXiv PDFs (parsed via GROBID), web pages, and academic PDFs. Unfetchable sources are marked as failures.
- Stage 3 (Quote Validity Check): Applies text normalization (casefolding, whitespace collapsing, hyphenation removal). Validates quotes via exact or fuzzy substring matching. Fuzzy trigram matching accepts quotes with >=90% overlap.
- Stage 4 (NLI Entailment Gate): Uses DeBERTa-v3-large fine-tuned on MNLI. Evidence quote serves as premise, statement as hypothesis. Filters semantically irrelevant quotes.
- Stage 5 (Repair-or-Drop): Failing triples are sent back to the base LLM with source text. The model chooses to provide a new quote, a new source+quote, or delete the statement. Repaired triples are re-verified through Stages 3-4. Final output includes a verified report and a JSONL audit log.
- Training budget: Not specified (method is inference-time only).

# Experiments
- Setup: Evaluated on a pilot subset of ReportBench containing 20 prompts (2 per domain across 10 domains). Models: GPT-4o and Gemini-2.5-Pro (temperature=0). NLI model: DeBERTa-v3-large (MNLI).
- Baselines: Standard (URL/arXiv only), Prompt-Only (structured triples without verification), QuoteVerify (full pipeline).
- Metrics: Match Rate (primary), Reference Precision/Recall, #Cited, Quote Valid, Entail Pass.
- Main Results (Table 1):
  - GPT-4o: Standard Match Rate 34.4%, Prompt-Only 56.9%, QuoteVerify 53.1%. QuoteVerify improves over Standard by +18.7pp (p=0.019). Quote Valid increases from 30.9% to 42.1%. Entail Pass increases from 17.0% to 31.8%. Reference recall drops from 0.68% to 0.23%. #Cited drops from 9.95 to 4.70.
  - Gemini-2.5-Pro: Standard Match Rate 26.7%, Prompt-Only 38.3%, QuoteVerify 39.2%. QuoteVerify improves over Standard by +12.5pp (p=0.011). Quote Valid increases from 4.0% to 44.6%. Entail Pass increases from 58.2% to 74.6%. Reference recall drops from 1.21% to 0.46%. #Cited drops from 14.70 to 9.15.
  - QuoteVerify significantly outperforms Standard (p<0.02) but does not significantly outperform Prompt-Only. Structured format alone yields +22.5pp (GPT-4o) and +11.6pp (Gemini) gains.
- Ablation Studies (Table 2, GPT-4o):
  - No-Entailment: Match Rate 58.8% (+5.7pp), Entail Pass 24.5% (-7.4pp). Demonstrates the NLI gate prevents semantically irrelevant quotes.
  - Drop-Only: Match Rate 53.6% (+0.4pp), #Cited 4.40. Indicates the repair step provides marginal value.
- Error Analysis (Figure 2):
  - Quote validity is the primary bottleneck. High fetch rates (89-100% for arXiv) do not translate to high pass rates (2.7-18.3%).
  - GPT-4o shows concentrated failures in Quote+Entailment (55.7% of triples). Gemini-2.5-Pro shows more distributed failures with higher fetch failures (26.9%).
  - Success by source type: arXiv fetch 89%/100%, overall pass 2.7%/18.3%. Academic PDF fetch 85%/67%, pass 4%/33%. Web page fetch 75%/46%, pass 8%/20%.
- Statistical testing: Paired bootstrap with 10K resamples.
