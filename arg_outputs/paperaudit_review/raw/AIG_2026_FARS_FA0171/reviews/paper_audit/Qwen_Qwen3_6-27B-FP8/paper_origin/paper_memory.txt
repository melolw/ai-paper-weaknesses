# Global Summary
This paper addresses the challenge of merging multiple task-specific LoRA adapters into a single multi-task adapter, where parameter interference degrades performance. The authors identify a critical failure mode in existing adaptive merging methods: entropy-based coefficient learning is reference-free and can produce "confidently wrong" predictions by over-optimizing for confidence without grounding in correct outputs. To solve this, the authors propose SourceJS-LoRA, which learns merge coefficients by minimizing Jensen-Shannon (JS) divergence between the merged model's predictions and each task expert's predictions on unlabeled data. Evaluated on 8 GLUE tasks using T5-base, SourceJS-LoRA achieves 83.10% average accuracy, outperforming the state-of-the-art DO-Merging by +2.29 points and entropy-based learning by +5.55 points. The method yields stable, positive merge coefficients (range 0.06–0.50, std 0.13), whereas entropy minimization produces extreme, unstable values with negative weights. Key caveats include evaluation limited to T5-base on GLUE, and a requirement for unlabeled data per task plus access to the original task-specific adapters during coefficient optimization.

# Abstract
- Identifies that merging LoRA adapters suffers from parameter interference and that entropy-based adaptive methods lack reference targets, leading to confidently wrong predictions.
- Proposes SourceJS-LoRA, which minimizes Jensen-Shannon divergence between merged model outputs and task expert predictions to anchor optimization.
- Reports 83.10% average accuracy on 8 GLUE tasks with T5-base, surpassing DO-Merging by +2.29 points and entropy-based coefficient learning by +5.55 points.
- Notes that the method produces stable, balanced coefficients, while entropy minimization yields extreme values with negative weights.

# Method
- Problem Setup: Defines merging K task-specific LoRA adapters {Δ₁, ..., Δₖ} into a single adapter Δ_merged = Σ γₖ Δₖ. The goal is to learn coefficients Γ = {γ₁, ..., γₖ}.
- Entropy Limitation: Critiques AdaMerging's entropy minimization objective (L_entropy) as reference-free. Without constraints on which predictions should be confident, optimization can collapse toward coefficients that produce overconfident but incorrect outputs, especially under LoRA interference.
- SourceJS-LoRA Objective: Minimizes JS divergence between the merged model and each task expert on that task's inputs: L_JS(Γ) = Σ E[D_JS(p_θₖ || p_θ_merged)]. This teacher-anchored objective forces the merged model to agree with expert predictions, preventing confidence collapse. For classification, distributions are computed over the label space Yₖ rather than the full vocabulary.
- Layer-wise Coefficients: Extends task-wise coefficients to layer-wise γₖ⁽ˡ⁾ for each layer l. For T5-base with LoRA on query/value projections in encoder/decoder, this yields 72 × 8 = 576 learnable parameters.
- Optimization: Uses Adam with a cosine learning rate schedule. Base model and adapters remain frozen. Adds L2 regularization toward uniform coefficients: L(Γ) = L_JS(Γ) + λ||Γ - Γ₀||₂². Requires only 128 unlabeled examples per task. Converges in approximately 300 steps with learning rate 0.02 and λ = 0.0002.

# Experiments
- Setup: Evaluates on 8 GLUE tasks (CoLA, MNLI, MRPC, QNLI, QQP, RTE, SST-2, STS-B). Uses T5-base (220M parameters). LoRA applied to query/value projections with rank r=16, α=32, dropout 0.05. Results averaged over 3 seeds (42, 123, 456).
- Baselines: Pre-trained T5-base, Uniform Merge (γₖ=1/8), DO-Merging (data-free magnitude decoupling/orthogonalization), Entropy Coeff (AdaMerging-style), Supervised Coeff (64 labeled samples/task), and Single-task LoRA (upper bound).
- Main Results: SourceJS-LoRA achieves 83.10% average accuracy. Outperforms DO-Merging (80.81%) by +2.29 points and Entropy Coeff (77.55%) by +5.55 points. Gap to single-task upper bound is 2.69 points. Entropy minimization underperforms Uniform Merge (77.55% vs 79.76%), particularly on CoLA (41.12% vs 51.04%) and MRPC (85.20% vs 92.22%). Largest gain on MNLI: 83.53% vs DO-Merging 67.88% (+15.65 points).
- Ablation Study: Task-wise coefficients (8 parameters) yield 82.69% accuracy. Layer-wise coefficients (576 parameters) with default hyperparameters drop to 82.01% (-0.68 points). Optimized layer-wise configuration reaches 83.10%, improving over task-wise by +0.41 points, with the largest gain on MNLI (+0.83 points).
- Coefficient Analysis: Entropy minimization produces unstable coefficients ranging from -3.04 to +2.50. SourceJS-LoRA produces balanced coefficients in range 0.06–0.50, all positive, with std=0.13 and range=0.44. Supervised coefficients show range=1.15, std=0.38, and 2 negative values. SourceJS-LoRA exhibits the smallest range, lowest standard deviation, and zero negative coefficients.
