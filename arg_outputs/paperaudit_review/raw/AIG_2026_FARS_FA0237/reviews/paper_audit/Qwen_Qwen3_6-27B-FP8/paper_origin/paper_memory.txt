# Global Summary
This paper addresses the knowledge-conflict failure mode in retrieval-augmented generation (RAG), where large language models (LLMs) ignore provided context and revert to memorized parametric knowledge. The authors hypothesize that entity surface forms in the context act as triggers for parametric recall. To test this, they propose Entity-Anonymized Context Prompts (EACP), a training-free prompting method that replaces entity names with anonymous placeholders (e.g., ENT_1) before generation. Evaluated on the ConFiQA-MC benchmark (6,000 multi-hop questions), EACP increases the context-faithful answer rate from 32.47% to 74.75% (+42.28 points) compared to a matched control condition, confirming anonymization as the active ingredient. The method generalizes across Llama-3.1-8B and Qwen2.5-7B, complements activation steering techniques, outperforms the training-based Context-DPO baseline without fine-tuning, and does not degrade performance on non-conflict contexts. Key caveats include a dependency on external named entity recognition (NER) for preprocessing, evaluation limited to English QA, and the note that the manuscript was generated by an automated research system.

# Abstract
- Problem: LLMs in RAG systems frequently fail to follow retrieved context when it conflicts with parametric knowledge, generating answers based on memorized facts instead.
- Hypothesis: Entity surface forms in the context trigger parametric recall, causing unfaithful behavior.
- Proposed Method: Entity-Anonymized Context Prompts (EACP), a training-free approach that replaces entity names with anonymous placeholders before prompting.
- Key Quantitative Result: On the ConFiQA-MC benchmark, EACP improves the context-faithful answer rate from 32.47% to 74.75%, a +42.28 point gain over a control condition with identical output formatting but no anonymization.
- Generalization & Comparisons: Improvements hold across Llama-3.1-8B and Qwen2.5-7B. EACP complements activation steering methods and outperforms Context-DPO (a fine-tuning-based approach) without requiring any model training.
- Caveat/Note: The paper includes a warning that it was generated by an automated research system. Code is publicly available. Dataset license and exact compute budgets are not specified in this section.

# Method
- Problem Formulation: Knowledge-conflict QA aims to maximize P(a|q,c) such that the answer a is grounded in context c, even when c contradicts pretraining memorization. The core challenge is that familiar entity names activate parametric associations.
- EACP Pipeline (4 steps):
  - Entity Extraction: Identifies named entities E from context c and question q. Experiments use benchmark-annotated entities for accuracy; standard NER is suggested for practice.
  - Anonymization: Creates a bijective mapping to placeholders (ENT_1, ENT_2, etc.) and applies boundary-aware, case-insensitive string replacement to c and q.
  - Inventory Construction: Lists placeholders with entity types only (e.g., ENT_1 (type=PERSON)), deliberately omitting original names to prevent parametric recovery.
  - Prompt Construction & Decoding: Combines inventory, anonymized context, and anonymized question. The model outputs placeholder-based answers, which are inverse-mapped to original names for evaluation.
- Experimental Controls (3 conditions):
  - Condition A (Baseline): Standard opinion-and-instruction prompting with original text.
  - Condition B (Control): Structured output with entity inventory and placeholder-based answers, but retains original entity names in context/question.
  - Condition C (EACP): Full anonymization with structured output. The C vs B comparison isolates the effect of anonymization.
- Optimizations:
  - Phantom Entity Tagging: Marks multiple-choice candidates not present in the context with [not in text] to prevent ungrounded selections.
  - Self-Consistency Decoding: Samples k=8 responses at temperature τ=0.7 and selects the majority answer to reduce variance.
- Missing Details: Exact NER system used for practical deployment, computational overhead of preprocessing, and handling of overlapping/ambiguous entities are not specified in this section.

# Experiments
- Setup & Dataset: Evaluated on ConFiQA-MC (Bi et al., 2024), containing 6,000 multi-hop questions with counterfactual contexts. Primary model: Llama-3.1-8B-Instruct. Secondary model: Qwen2.5-7B-Instruct.
- Metrics: Pc (context-faithful rate), Po (parametric-only rate), MR (memorization ratio = Po/(Pc+Po)×100), EM (exact match against context-faithful answer).
- Main Results (Llama-3.1-8B, 6,000 examples):
  - Condition A (Baseline): Pc=52.43%, Po=13.40%, MR=20.35%, EM=49.43%.
  - Condition B (Control): Pc=32.47%, Po=19.75%, MR=37.82%, EM=37.95%.
  - Condition C (EACP): Pc=74.75%, Po=10.77%, MR=12.59%, EM=81.80%.
  - Critical Comparison: C vs B yields +42.28 Pc and -25.23 MR, proving anonymization is the active ingredient. Structured output alone (B) harms performance relative to baseline A (-19.96 Pc).
  - Baseline Comparison: Outperforms Context-DPO (ref) which reports Pc=54.9% (noted as evaluated on a different model, Qwen2-7B).
- Complementarity with Activation Steering (1,500-example subset):
  - ContextFocus (D): Pc=54.93%, MR=26.16%, EM=6.93%.
  - EACP (C): Pc=72.87%, MR=13.25%, EM=80.00%.
  - EACP+ContextFocus (E): Pc=76.47%, Po=11.33%, MR=12.91%, EM=83.93%.
  - Claim: The combination achieves the best results, indicating EACP and activation steering address distinct failure modes.
- Cross-Model Generalization (6,000 examples):
  - Qwen2.5-7B-Instruct: Control B Pc=27.23%, EACP C Pc=76.43% (+49.20 points). MR drops from 41.14% to 13.94% (-27.20 points).
  - Claim: Larger gains on Qwen suggest models with stronger parametric priors benefit more from anonymization.
- No-Harm Control (500-example subset, original non-counterfactual contexts):
  - Baseline A EM=66.40%, Control B EM=79.80%, EACP C EM=88.00%.
  - Claim: EACP does not degrade performance when context aligns with parametric knowledge; it actually improves accuracy by encouraging context attention.
- Limitations & Caveats: Requires NER preprocessing (adds latency, potential extraction errors). Evaluation restricted to English QA. Other unfaithfulness sources (type-level priors, reasoning errors) may require additional interventions.
