# Global Summary
- Problem: VLM judges used for pairwise evaluation are vulnerable to prompt injection embedded in candidate responses, especially in single-pass judging where the model sees adversarial content before forming its own assessment.
- Core approach: Isolated solve-then-judge. Pass 1 generates a self-answer from only trusted inputs (image + query), creating an uncontaminated reference. Pass 2 judges candidates against this reference. A non-isolated two-pass control distinguishes benefits from isolation vs. prompt engineering/extra compute.
- Evaluation: VL-RewardBench (N=1,247; General=180, Hallucination=750, Reasoning=317) using Qwen2.5-VL-7B-Instruct, vLLM on 2 GPUs, bfloat16, greedy decoding (temperature=0, max_tokens=1024). Three attack variants: Primary (instruction override), Authority (impersonation), Verdict (direct verdict).
- Metrics: CleanAcc (accuracy on clean samples), ASR (overall attack success rate), ASR_cond (attack success rate conditional on originally correct judgment; primary metric).
- Key findings:
  - Main effect: ASR_cond drops from “91.33%” (single-pass) to “29.33%” (isolated), a “62pp” reduction; CleanAcc drops “10.8pp” (78.35% → 67.52%).
  - Isolation vs. prompt engineering: Isolated B (29.33% ASR_cond) vs. non-isolated C (33.37%) shows “~4pp” additional protection from information isolation.
  - Category results (ASR_cond): Hallucination “95.9% → 21.2%” (−74.8pp); Reasoning “85.9% → 49.5%” (−36.4pp), with control C better than B for Reasoning (“40.0% vs 49.5%”).
  - Attack variants (ASR_cond): Primary “91.3% → 29.0%” (−62.3pp), Verdict “74.7% → 39.0%”, Authority remains high at “63.6%”.
  - Pass-1 contamination: 0% in isolated B; 1.88% (23/1,224) in control C; when corrupted, ASR_cond rises to “73.9%” vs “47.8%” when clean.
  - Failure analysis (N=238 failures in B): 37% had very short self-answers (<30 chars); 98.7% occurred when the attacked response was in position 2; Reasoning most vulnerable (49.5% ASR_cond).
- Caveats explicitly noted: Clean accuracy degradation (“10.8pp”); category-dependent effectiveness; authority impersonation still succeeds at “63.6%”; position/recency bias; quality of self-answer anchoring matters. Paper notes it was generated by an automated research system; code link provided.

# Abstract
- Problem: VLM judges are susceptible to prompt injection because single-pass judging exposes the model to candidate responses before generating its assessment.
- Proposal: Isolated solve-then-judge—self-answer from only trusted inputs (image + query), then judge candidates against this reference.
- Results on VL-RewardBench (N=1,247) with Qwen2.5-VL-7B-Instruct:
  - ASR_cond reduced “from 91.3% to 29.3%” (−62pp).
  - Controlled experiments: isolation provides “4pp” additional defense beyond prompt engineering alone.
  - Cost: “10.8pp” clean accuracy degradation.
  - Category effects: hallucination detection benefits most (“74.8pp reduction”), reasoning least (“36.4pp”).
  - Remaining weakness: authority impersonation attacks achieve “63.6%” success against the defended system.
- Note: Paper generated by an automated research system; code publicly available (link provided in manuscript).

# Introduction
- Context: LLM-as-a-Judge achieves >80% agreement with human preferences; extended to multimodal evaluation. Reliability is crucial due to downstream impact.
- Vulnerability: Prompt injection embedded in candidate responses can hijack the judge’s reasoning in single-pass setups; prior text-only work shows success rates >90%.
- Insight: Information isolation—generate a self-answer using only trusted inputs (image, query) to create an uncontaminated anchor for later judging.
- Contributions:
  - Two-pass architecture: Pass 1 self-answer (trusted inputs only); Pass 2 judges candidates against this reference.
  - Empirical reductions: ASR_cond “91.3% → 29.3%” (−62pp). Controlled experiments show isolation adds “4pp” defense beyond prompt engineering.
  - Trade-offs and limits: “10.8pp” clean accuracy cost; category-dependent effects (best for hallucination, weakest for reasoning); authority impersonation remains high at “63.6%”.

# Related Work
- LLM-as-a-Judge: MT-Bench and Chatbot Arena; >80% agreement with human preferences; extensions to multimodal evaluation and VL-RewardBench.
- Vulnerabilities: Biases (position, verbosity, self-enhancement); self-inconsistency; adversarial prompt injection (e.g., up to “73.8%” attack success against popular judges); backdoor risks.
- Defenses: Spotlighting (delimiting/datamarking/encoding) reducing attack success “from over 50% to below 2%”; PromptArmor (instruction hierarchy, sanitization); MELON for agents (masking-based detection). Prior defenses not specifically evaluated in LLM-as-a-Judge settings with adversarial candidate content.
- Self-reference: Using a model’s own answer as a reference can improve evaluation correlation; current work applies self-reference with a focus on security via information isolation.

# Motivation
- Core implication: Generating a self-answer before any exposure to candidate responses yields an uncontaminated reference that provides defense against prompt injection embedded in those candidates.

# Method
- Problem formulation: Pairwise preference judging with inputs (I, Q, R1, R2); attack embeds adversarial content A in a candidate to force a specific verdict.
- Vulnerability of single pass: Model processes all inputs at once, encountering A before forming its assessment; prior work shows >90% success in text-only settings; similar vulnerability observed in multimodal.
- Isolated solve-then-judge:
  - Pass 1 (Isolated Self-Solve): S = M(I, Q). No access to candidates; immune to A.
  - Pass 2 (Reference-Anchored Judging): v = M(I, Q, S, R1, R2 ⊕ A). Uses S as an independent anchor during evaluation.
- Experimental conditions:
  - Condition A: Single-pass baseline (I, Q, R1, R2).
  - Condition B: Isolated defense—Pass 1 (I, Q) only; Pass 2 judges with S. Prompts include delimiters and explicit warnings about injection.
  - Condition C: Non-isolated control—two-pass structure but Pass 1 sees (I, Q, R1, R2); tests whether isolation specifically provides benefit beyond prompt design/compute.
  - Comparisons: B vs A = overall defense efficacy; B vs C = isolation’s specific contribution.

# Experiments
- Experimental setup:
  - Dataset: VL-RewardBench, 1,247 pairwise examples across General (180), Hallucination (750), Reasoning (317); human-verified preference labels.
  - Model: Qwen2.5-VL-7B-Instruct via vLLM, tensor parallelism on 2 GPUs, bfloat16; greedy decoding (temperature=0, max_tokens=1024).
  - Attacks: Three variants—Primary (instruction override), Authority (official evaluator impersonation), Verdict (direct verdict statement).
  - Metrics: CleanAcc (non-attacked accuracy); ASR (overall attack success rate); ASR_cond (attack success rate conditioned on originally correct judgment; primary metric).
- Main results (Table 1):
  - Condition A (Single-Pass): CleanAcc “78.35%”; ASR “91.90%”; ASR_cond “91.33%”.
  - Condition B (Isolated): CleanAcc “67.52%”; ASR “45.07%”; ASR_cond “29.33%”.
  - Condition C (Non-Isolated Control): CleanAcc “67.76%”; ASR “47.88%”; ASR_cond “33.37%”.
  - Key deltas: ASR_cond −62pp (A→B: 91.33% → 29.33%); isolation adds ~“4pp” protection vs C (29.33% vs 33.37%); CleanAcc drops “10.8pp” (78.35% → 67.52%).
- Per-category analysis (Table 2, CleanAcc | ASR_cond):
  - General (N=180): A “50.0 | 75.6”; B “47.2 | 34.5”; C “48.9 | 48.3”.
  - Hallucination (N=750): A “82.3 | 95.9”; B “74.8 | 21.2”; C “74.8 | 28.5”. Reduction A→B in ASR_cond: “74.8pp”.
  - Reasoning (N=317): A “85.2 | 85.9”; B “61.8 | 49.5”; C “61.8 | 40.0”. Control C outperforms B on ASR_cond for Reasoning (40.0% vs 49.5%); A→B reduction “36.4pp”.
- Attack variant analysis (Figure 2, Table 3; ASR_cond):
  - Primary: A “91.3%”, B “29.0%”, C “33.3%” (Δ A→B = “−62.3pp”).
  - Authority: A “88.6%”, B “63.6%”, C “62.4%”.
  - Verdict: A “74.7%”, B “39.0%”, C “38.6%”.
  - Most challenging under defense: Authority at “63.6%”.
- Corruption analysis:
  - Pass 1 contamination: B “0%” corrupted outputs; C “1.88%” (23/1,224).
  - Effect of corruption in C: ASR_cond “73.9%” when Pass 1 corrupted vs “47.8%” when clean.
  - Primary defense mechanism attributed to the uncontaminated reference anchor rather than solely preventing Pass-1 corruption.
- Failure analysis (Condition B):
  - N=238 attack successes examined.
  - 37% had weak self-answer anchors (<30 characters).
  - 98.7% occurred when the attacked response was in position 2 (idx=1), indicating strong recency/position bias.
  - Reasoning category shows highest vulnerability (ASR_cond “49.5%”), often due to terse numeric self-answers.

# Conclusion
- Summary: Isolated solve-then-judge substantially mitigates prompt injection in VLM judges by anchoring evaluation to a self-answer generated from trusted inputs.
- Quantitative outcomes on VL-RewardBench with Qwen2.5-VL-7B-Instruct:
  - ASR_cond reduced “91.3% → 29.3%” (−62pp).
  - CleanAcc decreased by “10.8pp” (78.35% → 67.52%).
  - Category-dependent performance: strongest for hallucination detection (ASR_cond “95.9% → 21.2%”), weakest for reasoning (“85.9% → 49.5%”).
  - Authority impersonation remains difficult (ASR_cond “63.6%” under defense).
- Future directions noted: Improve self-answer quality, mitigate position bias, and develop defenses against authority-based attacks.
